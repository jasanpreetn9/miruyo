My List gestures

Edit mode, not long-press. Swipes and long-press on a row already act on one entry (see Rows). Working with several entries starts with Edit, which pauses those gestures so a drag can never change progress.

Carry to a status. Hold a row in Edit and the whole selection lifts into a stack. Drop it on a status in the panel that rises from the bottom, within thumb reach. Move to… does the same with taps.

Up next is yours to order. On Planning, drag a row's handle to set the order. Remove works like the List editor: hold, then Undo. Try it all on 21a.
